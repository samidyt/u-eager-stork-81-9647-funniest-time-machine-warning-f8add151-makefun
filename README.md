One warning label for a time machine, written by the program in `main.ts` to
`/output/entry.txt` (program/v1 harness, Node 22, standard library only).

## The line (83 chars)

> WARNING: If you see your own grave, do not read the dates. Some spoilers are final.

## Why this line

- **A genuine warning label for a time machine:** phrased like a real safety
  notice, straight face, official calm.
- **Turns a real hazard into the joke:** seeing your own grave is the paradox
  made concrete, not named flatly.
- **Saves the surprise for the last words:** "Some spoilers are final" lands
  the laugh where the reader least expects it.
- **Tight:** 83 characters, every phrase doing work, one clean line.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

The program self-checks the gate before writing: 1–120 characters, not only
whitespace, exactly one line — and fails loudly instead of handing in a bad
entry. Verified: the line is 83 characters, one line, valid UTF-8.
